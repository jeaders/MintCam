✨ Open source webcam studio for Linux Mint

Your webcam, finally
simple and powerful

MintCam is a lightweight desktop application that transforms your webcam into a live camera, rapid photo capture, and video recorder designed for creators and video calls.

⬇ Download on GitHub View installation

Everything you need

Clear features, modern dark interface, and zero complications.

🎥

Live preview

Smooth webcam streaming with OpenCV. Choose device, resolution, and FPS in one click.

📸

Photo capture & timer

High-quality photos with 3/5/10 second timer and burst mode (3, 5, or 10 shots).

⏺

Video recording

Record locally with automatic codec fallback (mp4v, XVID, MJPG). Configurable clip duration limit.

🎨

Filters & adjustments

Grayscale, Sepia, Negative, High Contrast, Mirror. + brightness, contrast, and saturation controls.

📐

Multiple formats

16:9, 4:3, and 9:16 to adapt the frame for social media, presentations, or vertical video.

🌙

Native dark theme

Modern, lightweight interface designed for long sessions. Integrates perfectly with Linux Mint.

📷

QR/Barcode scanner

Real-time QR and barcode detection directly from the preview. Copy text with one click.

🎯

Focus assist

Laplacian variance scoring with visual indicator. Green = sharp, orange = soft, red = blurry.

👤

Face auto-framing

OpenCV Haar cascade face detection automatically crops and centers the frame on the detected face.

⏱️

Time-lapse recording

Capture frames at intervals and assemble them into an MP4 video automatically.

Lightweight and solid technology

Written in Python, UI with Qt 6, vision with OpenCV. Minimal dependencies, simple installation.

🐍 Python 3.10+
🖥️ PySide6 (Qt 6)
👁️ OpenCV 4.x
🔢 NumPy
🐧 Linux Mint 21+
📦 V4L2 + FFmpeg

Install in 2 minutes

Clone, virtualenv, and go. Or install as a desktop application.

# System dependencies sudo apt update sudo apt install python3 python3-venv python3-pip v4l-utils ffmpeg libxcb-cursor0 # Clone and setup git clone https://github.com/jeaders/MintCam.git cd MintCam python3 -m venv .venv source .venv/bin/activate pip install -r requirements.txt # Run chmod +x run.sh && ./run.sh
# After creating virtualenv and installing dependencies chmod +x install-local.sh ./install-local.sh # Now search "MintCam" in the applications menu # or run from terminal: mintcam # Uninstall rm -f ~/.local/share/applications/mintcam.desktop rm -rf ~/.local/share/mintcam rm -f ~/.local/bin/mintcam
# Download the .deb from the latest release wget https://github.com/jeaders/MintCam/releases/latest/download/mintcam_0.1.0_all.deb # Install sudo dpkg -i mintcam_0.1.0_all.deb # If dependencies are missing sudo apt install -f # Run from menu or terminal mintcam # Uninstall sudo dpkg --purge mintcam
