MintCam

Webcam app for Linux Mint — signed APT repository

Install in one command 
curl -fsSL https://jeaders.github.io/MintCam/apt/install.sh | sudo bash

Adds this repository (with its signing key), then installs mintcam with apt. After that MintCam appears in the Software Manager and updates arrive through Update Manager.

Manual installation

sudo install -d -m 0755 /etc/apt/keyrings
curl -fsSL https://jeaders.github.io/MintCam/apt/mintcam-archive-key.asc \
  | sudo gpg --dearmor --yes -o /etc/apt/keyrings/mintcam.gpg
echo "deb [signed-by=/etc/apt/keyrings/mintcam.gpg] https://jeaders.github.io/MintCam/apt stable main" \
  | sudo tee /etc/apt/sources.list.d/mintcam.list
sudo apt update
sudo apt install mintcam

Removal

sudo apt remove mintcam
sudo rm /etc/apt/sources.list.d/mintcam.list /etc/apt/keyrings/mintcam.gpg
sudo apt update

Verify the repository signature

curl -fsSL https://jeaders.github.io/MintCam/apt/mintcam-archive-key.asc | gpg --show-keys
